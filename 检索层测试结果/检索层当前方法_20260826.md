# 检索层当前方法

## 1. 公共入口

`HybridSearchEngine` 是当前只读入口。它组合以下可替换模块：

- `SnapshotStore`
- `QueryEmbedder`
- `VectorRetriever` / `ModalitySearcher` / `KeywordSearcher`
- `CandidateRanker`
- `EvidenceExpander`
- `EvidenceAssembler`

如果外部没有传入查询编码器，Engine 会创建 PixelRAG 会话，并在关闭时只关闭自己拥有的会话；外部传入的编码器不会被擅自关闭。

## 2. 候选搜索模块

候选搜索是检索层内部的第一个插槽，不是独立系统层。一个问题只通过 `PixelRAGQueryEmbedder` 编码一次，然后分别搜索 `text`、`table`、`visual` 三个 FAISS 索引。

每种模态同时执行两条召回路线：

- 归一化向量通过 `faiss.IndexFlatIP` 召回；
- `KeywordSearcher` 对 `embedding_text`、`context` 和原始内容执行 BM25，并检查完整问题短语。

BM25 使用 `k1=1.5`、`b=0.75`。英文和数字保留连续术语；中文保留连续片段并生成重叠二元词。关键词结果即使落在向量 Top K 之外，也可以加入候选集合。

候选采用加权 RRF：

```text
score = 1.0 × modality_weight / (60 + vector_rank)
      + 1.5 / (60 + keyword_rank)
      + 2.0 / 61                         # exact_match 时
```

模态权重为 text 1.00、table 1.00、visual 1.10。纯向量候选要求 `raw_score >= 0.40`，关键词命中可以绕过该向量门槛。之后按 `record_id`、同模态内容哈希和文字来源块重叠规则去重，输出 `RankedSearchResult` Top K。

视觉候选还要通过最终证据资格门：`coarse_only`、`llm_eligible=false` 及旧快照中的整页 PDF 视觉占位不会进入结果。

## 3. 有界上下文扩展

`EvidenceExpander` 默认：

| 参数 | 默认值 | 允许范围 |
|---|---:|---:|
| `previous_hops` | 1 | 0–2 |
| `next_hops` | 2 | 0–2 |

文字核心候选直接作为锚点。表格或视觉候选会先在同文档同页寻找文字锚点；如果问题完整短语出现在某个同页文字块中，优先选它，否则选稳定的第一条。

新快照通过 `previous_record_id` 和 `next_record_id` 显式链接相邻文字，可跨页但不能跨文档。旧 schema 2.0 快照没有链接时，使用受限索引邻居兼容策略。

扩展器只附加邻居，不判断邻居是否与问题相关；这是为了保留跨块句子、标题与下一段解释，同时把范围限制在最多前 1 后 2。

## 4. 证据组装

`EvidenceAssembler` 先创建核心 `core` block，再加入 `neighbor` blocks。之后收集这些块所在的 `page`、`slide` 或 `sheet`，从同一文档同一容器中寻找相关表格和视觉对象。

相关对象排序依据：

1. 可搜索文本是否包含完整问题；
2. bbox 中心与核心/邻居 bbox 的距离；
3. 相同时表格在视觉之前；
4. `record_id` 保证确定性。

限制为每个容器最多 2 条 related，总 related 最多 8 条。整页 PDF 视觉、`coarse_only` 和不可给 LLM 的视觉不会被组装。

## 5. 证据顺序

最终 `evidence_blocks` 按以下顺序稳定排列：

1. 容器类型：page、slide、sheet；
2. 容器编号；
3. bbox 的 top、left；
4. 模态：text、table、visual；
5. `record_id`。

每个 block 标记 `role=core|neighbor|related`，相邻文字还标记 `previous_context`、`next_context` 或 `same_page_text`。

## 6. 回链与显示

每个命中同时保留原始核心内容和扩展证据：

- `provenance` 与 `source_block_ids`
- `adjacent_context`
- `context_pages`
- `evidence_blocks`
- 视觉 `asset_path`

Studio 可以显示命中排名、证据块角色、跨页范围、文字/表格/图片内容和原始页。视觉路径必须解析到当前快照目录内部，否则拒绝返回。

## 7. 当前边界

检索层没有把邻居或 related 对象重新打相关性分，也没有调用 reranker 或 LLM。它提供的是“有界、可追溯、适合后续回答层读取”的证据包。
